# РПКА — концепция сайта

Прототип главной страницы Российской парфюмерно-косметической ассоциации (концепция D) и документ с пояснениями.

- `index.html` — прототип главной
- `concept.html` — документ концепции: путь к решению, токены, цвет по Иттену, типографика, движение, структура

Сайт статический, собирается без зависимостей:

```
python3 src/build.py   # шаблоны из src/ → index.html, concept.html
python3 -m http.server # локальный просмотр
```

Стек: HTML, CSS-переменные (`assets/css/tokens.css`), GSAP 3 (ScrollTrigger, SplitText) и Lenis — лежат в `vendor/`.

Тексты в квадратных скобках — заглушки. Страницы закрыты от индексации (`noindex`, `robots.txt`).
